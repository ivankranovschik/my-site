# Симулятор лифта ЩЛЗ (2011 года проекта)

Интерактивный веб-симулятор пассажирского лифта Щербинского лифтостроительного завода (ЩЛЗ) на 16 этажей.

## Особенности
- Аутентичный зеленый цвет купе кабины тех лет.
- Панель приказов со светящимися желтыми кнопками.
- Семисегментное табло индикации этажа.
- Реалистичные тайминги движения и открытия дверей.
- Кнопки принудительного открытия/закрытия дверей и связи с диспетчером.

## Как запустить локально
Просто откройте файл `index.html` в любом современном браузере.
